# Security Policy

## Supported versions

Eval Forge is a static website. Only the version currently deployed from `main` is supported.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report it privately using GitHub's **Security** tab for this repository: choose **Report a vulnerability**. If that option isn't available, contact the maintainers through [github.com/eval-forge](https://github.com/eval-forge) and ask for a private channel.

Include:

- a description of the issue and its impact,
- the page or file affected,
- steps to reproduce, and any proof of concept,
- your name or handle, if you'd like credit.

## What to expect

- We'll acknowledge your report as soon as we can.
- We'll look into it, keep you updated, and aim to fix confirmed issues promptly.
- We'll credit you in the fix, if you want that.

## Scope

In scope: the code and content in this repository and the published site.

Out of scope: issues in third-party services, models, or CDNs that this site links to. Report those to their owners.
